# ⚡ QuickGPT

> A full-stack AI platform for conversations, web-powered answers, and AI image generation.

QuickGPT is a modern AI assistant platform built with **React, Node.js, Express, MongoDB, Gemini, Tavily, and ImageKit**.

The project is designed to go beyond a basic chatbot by combining conversational AI, real-time web search, AI image generation, authentication, credit management, and persistent chat history into one full-stack application.

---

## 🚀 Features

### 💬 AI Chat

- Conversational AI powered by Google Gemini
- Persistent conversations
- Chat history
- User authentication
- Credit-based usage system
- Automatic message storage

### 🌐 Web Search

QuickGPT can retrieve current information from the web using Tavily.

Useful for questions involving:

- Current events
- Sports
- News
- Recent information
- Real-time topics

Search results are passed to the AI to generate a contextual response.
